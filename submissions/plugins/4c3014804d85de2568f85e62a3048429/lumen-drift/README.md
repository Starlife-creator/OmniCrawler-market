# Lumen Drift（lumen-drift）

版本：0.6.0 · 渲染生命周期、缩略预览与设置 · 2026-10-04。发行包使用现有作者身份签名；修改载荷后必须重新签名。

## 功能

先配置再启动 live，启动后 set 失败会停止新任务并清除无效背景。支持 HTML 禁脚本静态缩略预览（320×180，明确显示到背景）；快照句柄缓存最多 8 项，刷新与失败后清空。

## 配置与状态

新增 state:read/state:write 保存资源视觉偏好，schema 1，最多 256 项。按可选设置分组与资源相对身份保存，临时授权句柄不持久化；不同目录的同名资源可用不同分组。持久状态不可用时保留会话设置。

## 权限与数据去向

声明权限：resources:read, surfaces:background, render:local, render:scripted, state:read, state:write。resources:read 读取授权资源；surfaces:background 呈现背景；render:local 用于静态快照；render:scripted 用于隔离动态 HTML。宿主没有内嵌图片预览组件，因此缩略预览会替换当前背景；点击资源恢复完整播放。宿主单 live 会话，失败时不保证无闪烁恢复旧动态背景。手动暂停冻结展示，宿主仍可能生成帧，不承诺节能。系统自动暂停、多显示器和完整 Wallpaper Engine 运行不属于此版本。

## 兼容与许可

最低核心版本：0.12.0；执行模式：subprocess；许可：MIT。

# Lumen Drift（流光漂移）

## 0.5.0 开发版（2026-10-03，待作者签名）

搜索标签或资源路径，每页 50 项；扫描仍受宿主每次 2000 项和插件 500 资源上限约束，达到上限提示可能不完整，可选择较小子目录。分页只用于已扫描列表，宿主当前不提供目录游标。

图片与视频不再要求 HTML 渲染能力；动态 HTML 失败可降级静态快照，静态能力也缺失时显示恢复提示。背景参数先由宿主接受，再发布新背景；所有调用成功后才更新播放状态。

以上为当前行为；下文旧版本内容保留为历史说明。


Lumen Drift 是契约 2 隔离插件，用宿主固定组件浏览本地媒体和 Wallpaper Engine
创意工坊资源。插件只处理资源目录结构和 `project.json`；目录授权、媒体播放、HTML
快照、面板布局及生命周期均由 OmniCrawler 通用宿主能力负责。

用户可点击自动查找 Wallpaper Engine 创意工坊（Steam App ID 431960），也可手动选择目录。
自动发现同样由用户按钮触发，只返回当前插件会话的不透明句柄。图片、GIF 和视频由宿主播放；
本地 HTML 默认断网、禁用脚本并转成静态快照。额外批准 `render:scripted` 后可主动选择隔离
动态背景；宿主限制为单插件单流、最高 5 FPS、最高 1920×1080，并持续阻止网络、下载与交互。
网页引用的相对 CSS、脚本和图片只能从同一用户授权目录按有界资源路由读取。
Scene `.pkg`、程序型壁纸和外部网络资源不会执行。

0.4.0 使用宿主 `surface.background` v2 语义背景槽位：媒体始终位于操作控件底层且不接收输入，
可以选择整个应用客户区、完整工作区或当前内容画布，并提供清晰、平衡、专注、沉浸和纯背景
预设。背景可见度、前景面板不透明度、遮罩、静态模糊与适配方式均由宿主限制和渲染；动态
媒体可以暂停，也可以在受支持资源间前后切换。窗口最小化或隐藏时宿主自动暂停动态渲染。

面板可在宿主允许的区域移动、浮动和调整尺寸。插件不能读取原始目录路径、创建 QWidget，
也不能把网页注入主进程。

产品方向只借鉴动态壁纸工具的自动发现和媒体背景方法论。实现完全原创，许可证为 MIT。

## 使用与故障恢复

需要 OmniCrawler 0.12.0 或更高版本，并通过宿主能力检查。当前目录为未签名的 0.4.0
开发稿，不应覆盖旧版已签名包；完成验证后再生成新的完整包与签名。

1. 在当前项目启用插件、确认权限，使用自动发现或手动选择目录。
2. 按“全部 / 图片与 GIF / 视频 / 本地 HTML / 不支持的项目”筛选资源。
   “上一个 / 下一个”仅在当前分类的受支持资源之间循环。
3. 添加或移走文件后点击“刷新当前目录”；刷新使用现有授权，不会扩大访问范围。
4. 面板显示当前背景与暂停状态。“停用背景”保留目录和插件启用状态；
   要停止插件本身，应在市场选择“在当前项目禁用”。

每次最多枚举 2000 个目录项并显示 500 个资源。大型创意工坊目录请手动选择更小的子目录；
此上限不是全库已扫描完成的保证。不可读取或损坏的项目描述不会阻止其他散装媒体出现。
扩展名识别仅表示可以尝试呈现，实际视频解码能力取决于宿主及当前平台。
目录失效或文件被移动时，界面提供重新授权/选择目录的恢复提示，不展示可能包含私人路径的底层错误。
显示设置只在宿主接受后更新；切换目录扫描失败时保留原目录清单。
