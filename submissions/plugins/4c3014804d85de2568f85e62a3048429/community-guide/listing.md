# community-guide（community-guide）

版本：1.2.0 · 新人贡献路径与投稿导航 · 2026-10-04。发行包使用现有作者身份签名；修改载荷后必须重新签名。

## 功能

增加中英对照的阅读、选任务、提交验证、回应审阅路径；分别提供插件投稿流程、模板目录与市场安全政策入口。

## 配置与状态

安装即用，无配置、无网络调用、无持久状态。官方链接经宿主确认后由系统浏览器打开；仓库是否启用 Discussions 以实时页面为准。

## 权限与数据去向

声明权限：无。新增入口已通过 GitHub contents API 验证对应文档/目录存在。插件不读取讨论区、不登录、不代用户发言。

## 兼容与许可

最低核心版本：0.14.0；执行模式：subprocess；许可：MIT。
