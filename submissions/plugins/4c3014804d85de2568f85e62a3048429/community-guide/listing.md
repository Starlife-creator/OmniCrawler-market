# 官方社区引导（community-guide）

## 一句话简介
仓库 Discussions / Issues / 贡献指南的外链导航面板——零网络、零凭据、纯静态。

## 功能说明
- 形态：按 2026-09-20 拍板落在「外链引导」分支（当前仓库未启用 Discussions，`has_discussions=false`）
- UI：宿主声明式 `rich_text` 组件（结构化链接段），链接点击经确认后在系统浏览器打开
- **零网络**：不申请任何网络能力、不发任何请求；仓库启用 Discussions 后可升级为 API 拉取形态

## 适用场景
- 找到提问 / 报缺陷 / 提需求的正确入口
- 查看贡献指南与行为准则

## 占位符说明
无需配置，安装即用。

## 兼容性
- `min_core_version: >= 0.14.0`（需要核心的 `view.richtext` 能力；更早版本会在加载阶段明确拒载）
- `license: MIT`

## 合规与限制
纯静态链接面板，无任何数据采集。外链目标为 GitHub 平台页面，平台条款以 GitHub 为准。

## 使用方式
1. 在 GUI 插件市场安装（信任根验签通过）
2. 打开「社区」面板，点击需要的入口（确认后在浏览器打开）
