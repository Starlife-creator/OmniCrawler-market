# 文档工作台

把任意文档变成结构化数据：**任意格式互转**（CSV/JSONL/XLSX/Parquet/DuckDB）、
文档解析（PDF/Office/EPUB/HTML/Markdown）、OCR、字段抽取、人工复核、五表导出。
全流程在本机完成，每条字段都带来源证据。

## 适合谁

- 处理大量扫描件 / 电子发票 / 合同，需要把关键字段抽成表格的人
- 需要**字段级证据**（这行数字来自哪一页、哪个位置、置信度多少）的合规场景
- 不希望把文档上传到任何云端服务的场景

## 两种用法

**作为 OmniCrawler 插件**（推荐）：在「插件市场」里安装本插件，
宿主即获得完整 文档工作台。卸载后宿主恢复轻量形态，互不影响。

## 能力

- 摄取：批量导入 PDF，识别文字版 / 扫描版并分别处理
- OCR：支持 PaddleOCR 与 Tesseract；也可调用已验签的独立 OCR 组件
- 抽取：模板字段 + 规则 + 可选 LLM 增强，全部可离线运行
- 复核：人工确认 / 拒绝，保留复核痕迹
- 导出：`results.csv`、`review_queue.csv`、`字段长表`、`文件清单`、`错误记录`
  五张表，同时产出 Excel 与 Markdown

## 数据与隐私

- 所有处理在本机完成；唯一可能的出网是 LLM 字段抽取，且**必须显式配置**才启用
- LLM 内容外发另有隐私闸门（未显式开启 `allow_pdf_content` 即拒发）
- 卸载插件不会删除你的项目数据
