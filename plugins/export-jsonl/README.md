# export-jsonl · JSON Lines 导出

把采集结果导出成每行一条独立 JSON 的 `.jsonl`。

## 为什么用 JSONL

- 每行一条 —— 可以 `cat` 看、按行流式处理，不需要把整个结果集塞进内存；
- `jq` / DuckDB / Spark 都能直接读；
- 相比「一个巨大 JSON 数组」，大结果集上不会 OOM。

## 权限与数据去向

**零权限**。隔离子进程、纯函数、不读文件、不联网、无第三方依赖。

## 一个刻意的取舍：超长行**跳过并回报**

单行超过 `max_line_bytes`（默认 1 MiB）的条目会被跳过，并计入返回值的 `skipped`。
超长的行在 JSONL 里几乎无法被下游工具解析，而且往往意味着上游抓到了整个 HTML 页面。
**跳过必须显式回报**，不能静默丢弃。
