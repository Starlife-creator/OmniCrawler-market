# field-alias · 字段别名归一

把不同站点/语言的**同义列名**统一成一套，用于跨站合并。

## 解决的问题

同一次跨站采集里，「商品名」可能叫 `标题`、`名称`、`title`、`product_name`。
合并多来源时下游拿到的是**四列**，每列都只有一部分行有值 —— 得再写一遍清洗脚本。

给一张别名表即可：

```yaml
transformers:
  - name: field-alias
    options:
      aliases:
        商品名: [标题, 名称, title, product_name]
        价格:   [价格, price, 售价]
```

## 三条判据（刻意保守）

| 判据 | 为什么 |
|---|---|
| **只合并同一目标名下的别名** | 「卡片标题」和「正文」是两回事；模糊匹配猜错比不做更糟 |
| **冲突如实回报，不静默取舍** | 同一行两个别名都有不同值时，保留第一个非空并写进 `conflicts` |
| **原列默认不删** | 用户要能回查原始数据；`drop_source: true` 才删 |

空白（`None` / 空串 / 纯空白 / 空列表）不算「有值」——
否则一个空列会把有值的同义列压掉。

## 输出

```json
{
  "items": [...],
  "renamed": {"商品名": ["title", "名称", "标题"]},
  "conflicts": [{"index": 0, "field": "商品名", "values": {"标题": "A", "名称": "B"}}],
  "dropped": [],
  "summary": {"targets": 2, "merged": {...}, "conflict_count": 1, "dropped": []},
  "summary_text": "别名归一完成：合并 2 个目标列；1 处取值冲突已如实回报（保留每行第一个非空值）"
}
```

## 权限与数据去向

**零权限**（`permissions: []`）。运行于隔离子进程，**不能 import omnicrawler**，
不读文件、不联网、无第三方依赖 —— 纯函数，输入来自 payload，输出是纯数据结构。

## 兼容性

- OmniCrawler `>=0.7.0`
- 许可：MIT
- 执行模式：`subprocess`（沙箱）

## 已知限制

- 不做模糊/相似度匹配（见上表第一条）。列名差异很大的请显式写进别名表。
- 一次调用只处理一层别名（不做链式传递）。
